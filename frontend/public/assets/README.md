# Waitlist illustration slots

These original, hand-authored SVGs are placeholders for future custom illustrations. They are intentionally text-free and use the visual tokens in the repository's `DESIGN.md`.

- `pattern-sequence.svg` — four-stage scam-pressure pattern
- `product-preview.svg` — call waveform and abstract signal panel
- `audience-support.svg` — connected home and support motif
- `privacy-boundary.svg` — audio waveform inside an in-memory processing boundary
- `waitlist-cta.svg` — quiet waveform accent for the final call to action

To replace a slot, add the new image to this folder and update the matching `/assets/<filename>` reference in `frontend/src/WaitlistLanding.tsx`. Keep the hero illustration in CSS/SVG code. Generated and added raster images for this project belong in this folder.
